# 📚 CLI 个人知识库

> 基于 Python + MySQL 的命令行笔记管理工具，支持增删改查、标签分类、全文搜索、Markdown/HTML 导出与标签可视化统计。

## ✨ 功能特性

- 📝 **笔记管理**：添加、查看、编辑、删除笔记
- 🏷️ **标签系统**：为笔记打标签，按标签筛选
- 🔍 **全文搜索**：按关键词搜索标题和内容
- 📊 **可视化统计**：标签分布柱状图 + 饼图（matplotlib）
- 📤 **多格式导出**：Markdown / HTML 报告
- 🗄️ **MySQL 存储**：数据持久化，支持复杂查询

## 🛠️ 技术栈

- **语言**：Python 3.13
- **数据库**：MySQL 8.x
- **依赖库**：pymysql、tabulate、matplotlib
- **版本控制**：Git + GitHub

## 📋 环境要求

- Python 3.10+
- MySQL 5.7+（需提前启动服务）
- Git
